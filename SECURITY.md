---

## Reporting a Vulnerability

The AssetPulse team takes security seriously. If you discover a security vulnerability or vulnerability in user data isolation, cryptographic session management, or financial calculations, please help us protect our users by following responsible disclosure practices:

1. **Do not disclose the vulnerability publicly** through GitHub issues, discussions, or social media.
2. Please report the issue via GitHub's private vulnerability reporting feature:
   - Go to the **Security** tab of the repository on GitHub.
   - Click on **Report a vulnerability** to open a private advisory.
3. Include the following details to help us assess the vulnerability promptly:
   - Type of vulnerability (e.g., IDOR, SQL injection, session hijacking).
   - Step-by-step instructions or proof-of-concept to reproduce the behavior.
   - Any suggested remediations or mitigations.

We will acknowledge receipt within 48 hours and work with you on a resolution before any public release.
